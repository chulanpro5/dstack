# Rules

Everything the user decided. One dated line each. **Newest wins.** If a rule changes, edit or delete the
old line. Do not add a contradiction. A proposal from an agent is not a rule until the user confirms it.

Format: `- **R-<MMDD>-<n>** · <YYYY-MM-DD> · <task-slug or "general"> · <the rule>`

## How we work

What the agent may do alone, what needs the user, PR and release flow, checks, scope.

- **R-<MMDD>-1** · <YYYY-MM-DD> · general · <rule>

## Decisions

Product and technical choices, grouped by topic.
